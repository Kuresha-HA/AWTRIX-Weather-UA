# AWTRIX Погода + Прогноз + 🌕️ для Home Assistant

Комплексний погодний блюпринт для **AWTRIX 3** та **AWTRIX NG**, який перетворює AWTRIX на компактну інформаційну панель із поточною погодою, погодинним прогнозом, температурною шкалою, фазами Місяця та повідомленнями про схід і захід Сонця.

### ✨ Основні можливості

- підтримка **AWTRIX 3 (0.98)** та **AWTRIX NG**;
- автоматичне визначення покоління прошивки для кожного пристрою;
- одночасне використання AWTRIX 3 та AWTRIX NG в одній автоматизації;
- відображення поточного стану погоди;
- відображення поточної температури;
- можливість брати поточну температуру з **окремого сенсора** — наприклад, локальної метеостанції або датчика температури за вікном;
- погодинний прогноз через стандартний Home Assistant `weather.get_forecasts`;
- кольорова смуга погодинного прогнозу в нижній частині дисплея;
- до **24 годин** прогнозу;
- автоматичний розрахунок кольору температури за заданою JSON-мапою;
- плавна інтерполяція кольорів між температурними точками;
- відображення всіх основних фаз Місяця;
- власна 8×8 піксельна графіка Місяця;
- різні режими показу Місяця: ніколи, завжди, після сходу або після сходу + вночі;
- можливість замінити нічну погодну іконку на фазу Місяця;
- повідомлення про найближчий схід або захід Сонця;
- точний або відносний формат часу Сонця;
- налаштовувані погодні іконки;
- окремі користувацькі застосунки `KU_Weather` та `KU_Weather_sun`.

### 🌡️ Джерела даних

Блюпринт не прив'язаний до одного погодного сервісу.

**Погодинний прогноз** може надходити з будь-якої інтеграції Home Assistant, яка надає погодинний прогноз через домен `weather`. Зокрема, блюпринт тестувався з Weatherflow та OpenWeather.

**Поточна температура** може надходити з іншого сенсора. Наприклад:

- прогноз — з OpenWeather;
- поточна температура — з домашньої метеостанції;
- або поточна температура — з окремого температурного сенсора, встановленого за вікном.

Тобто джерело прогнозу та джерело фактичної температури **не повинні бути одним і тим самим сенсором**.

### 📊 Смуга погодинного прогнозу

У нижній частині дисплея формується піксельна смуга.

Кожен сегмент відповідає окремій годині прогнозу, а його колір залежить від прогнозованої температури. Кількість годин задається в налаштуваннях — від 0 до 24.

Кольори можна повністю налаштувати через JSON-мапу температурних значень. Між заданими точками використовується автоматична інтерполяція кольору.

### 🌕 Місяць

Блюпринт підтримує:

- 🌑 молодик;
- 🌒 серп, що зростає;
- 🌓 першу чверть;
- 🌔 опуклий Місяць, що зростає;
- 🌕 повний Місяць;
- 🌖 опуклий Місяць, що спадає;
- 🌗 останню чверть;
- 🌘 серп, що спадає.

Для визначення поточної фази використовується стандартна інтеграція **Moon** Home Assistant.

Для визначення сходу/заходу Місяця використовується окремий REST-сенсор із атрибутами `moonrise`, `moonset` та `moon_altitude`.

### ☀️ Схід і захід Сонця

Блюпринт може показувати окреме повідомлення перед найближчим сходом або заходом Сонця.

Доступні два формати:

- **точний час** — наприклад `06:42`;
- **відносний час** — наприклад `12 min` або `1h 12m`.

Поріг появи повідомлення та тривалість його відображення налаштовуються окремо.

### 🔌 AWTRIX 3 та AWTRIX NG

Блюпринт автоматично визначає тип пристрою та використовує відповідний MQTT-топік і формат payload.

- **AWTRIX 3:** `<device_topic>/custom/<app>`
- **AWTRIX NG:** `<mqtt_prefix>/cmd/apps/pushed/<app>`

Тому можна вибрати декілька AWTRIX, навіть якщо частина пристроїв працює на AWTRIX 3, а частина — на AWTRIX NG.

### ⚙️ Налаштування

Через інтерфейс Home Assistant можна налаштувати:

- пристрої AWTRIX;
- сенсор погодинного прогнозу;
- кількість годин прогнозу;
- окремий сенсор поточної температури;
- кількість десяткових знаків;
- суфікс температури;
- температурну колірну матрицю;
- сенсор фази Місяця;
- сенсор сходу/заходу Місяця;
- режим відображення Місяця;
- заміну погодних іконок на Місяць;
- показ сходу/заходу Сонця;
- поріг часу сповіщення;
- формат часу;
- тривалість показу прогнозу;
- тривалість повідомлення про Сонце;
- ID погодних іконок.

### ⚠️ Необхідні умови

Для роботи потрібні:

1. Home Assistant з MQTT.
2. AWTRIX 3 або AWTRIX NG.
3. `weather`-сенсор із погодинним прогнозом, сумісним із `weather.get_forecasts`.
4. Інтеграція **Moon**.
5. REST-сенсор для `moonrise`, `moonset` та `moon_altitude`.
6. Необхідні погодні іконки, завантажені на AWTRIX.
